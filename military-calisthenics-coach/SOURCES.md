## Verification status — read first

- **Access date for every entry: 2026-11-09.**
- The build environment's network policy blocked all source hosts (eparmedx.com, acsm.org, acog.org, cdc.gov, heart.org, armypubs.army.mil, fitness.marines.mil, who.int, nice.org.uk, nhs.uk …). `curl` returned `CONNECT tunnel failed, response 403` and WebFetch returned DNS errors. **No source document was opened in full.** Titles, dates, DOIs and key facts come from web-search result snippets (often secondary summaries); see `docs/research_notes_2026-11-09.md` for item-by-item status, including what is unconfirmed.
- Before production use, a qualified person must open each primary document and confirm the facts used in the rules below.
- No endorsement, certification or approval by any publisher is claimed.

## Licensing decisions

- **PAR-Q+**: copies of the form require it to be used complete and unchanged; no licence for software embedding or translation was found. The app therefore does **not** reproduce or translate PAR-Q+. It uses its own Arabic questions mapped to the PAR-Q+ topics and labels them as custom. Coaches who need the official form should print it from eparmedx.com.
- **Borg RPE / CR10**: copyrighted and commercially licensed. Not embedded. The app uses a plain 0–10 effort number in its own wording.
- **OMNI pictorial scale**: licence unknown, so it is not reproduced.
- **US Army FM 7-22 / ATP 7-22.02**: US Government works. Only exercise **names** are used; all descriptions and drawings are original.
- **NHS / NIA / CDC / WHO**: cited as reading references only. No text was copied.
- **Exercise illustrations**: all original, generated by code from per-exercise pose data. No third-party images are used.
